# MA5 每日复盘设计规格

最终视觉参考：

- `ma5-daily-review-primary.png`：默认审计工作台。
- `ma5-daily-review-detail.png`：股票详情抽屉与证据核对状态。

## 设计系统

- 背景：真深石墨色，页面 `#071016`，一级表面 `#0c151c`，二级表面 `#101b23`。
- 边框：`#27343d` 细线；冲突/风险使用 `#ff6464`，提醒使用 `#f1b84b`，确认使用 `#69d36f`，中性数据使用 `#55bde9`。
- 文字：主文字 `#edf2f5`，次文字 `#9aa6ae`，禁用文字 `#65717a`。
- 字体：`Segoe UI Variable`, `Microsoft YaHei UI`, sans-serif；数字使用 tabular numerals，证据时间可用 `Cascadia Mono`。
- 形状：小圆角 4-6px、开放式指标轨道、表格、时间线和状态条；避免大卡片网格、渐变、玻璃拟态和装饰性徽章。
- 状态不可只靠颜色，必须同时有图标/形状和中文文字。

## 信息层级

1. 顶栏：交易日、复盘状态、覆盖时间、券商核对状态、刷新、K 线入口。
2. 今日结论：券商成交事实 + MA5 策略事实。
3. 最高优先级冲突：本地订单账本与 Alpaca 订单不一致。
4. 指标轨道：买入股票、已卖出、订单数、未成交买入、策略候选、排除、当前持仓、成交净现金流。
5. 统一决策表：券商成交、买入未成、策略未买、排除、窗口外最接近。
6. 右栏：证据时间线与必须核对队列。
7. 下方：策略漏斗、券商成交闭环、未买原因、订单流水、三时段复盘、证据与数据健康。
8. 股票详情抽屉：成交生命周期、核对清单、记录一致性、策略上下文、原始证据。

## 关键口径

- 本地订单文件缺失不是“0 笔券商订单”。
- `DRY_RUN` 单独标记为模拟，不计入真实成交。
- “待买”只在 `09:30 <= t < 12:00 ET` 且交易日实时窗口仍开放时使用。
- 历史复盘分开显示 `buy_window_best`、`all_day_closest` 和 `latest`。
- 当日成交净现金流 = 当日卖出成交额 - 当日买入成交额；必须标注未含费用且不等同券商已实现盈亏。
- 券商订单未与本地 order_id 匹配时，来源标记为“尚未归因”，不得猜测为本策略或人工下单。
